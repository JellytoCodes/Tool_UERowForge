## D-08에서 의도적으로 줄인 것

유지하는 것은 에셋 경로 읽기·로드 실패·행 타입 검증이다. 제거한 것은 테이블마다 const 행 포인터/행 복사본을 반환하던 두 개의 전용 조회 함수와 자체 타입 템플릿이다.

엔진 API인 `LoadObject<UDataTable>`/호출 측 `FindRow<T>`까지 금지하는 뜻은 아니다. 생성기의 관리 인터페이스를 단순화한 결정이다.

## D-11/D-12에서 혼동하면 안 되는 것

`예정 경로 기록`은 실제 에셋이 없어도 가능하다. `정상 .uasset 생성`은 실제 Row Struct가 로드돼 있어야 가능하다. `에셋 생성 완료`와 `Subsystem에서 런타임 로드 성공`도 같은 상태가 아니다.

현재 코드가 INI 등록을 에셋 저장 성공에 묶어 둔 것은 안전 정책이었다. 앞으로 예정 등록을 허용하려면 기존 실패/이관/소유권 테스트를 함께 바꿔야 한다. 단순히 문구만 `자동 연결 완료`로 바꾸지 않는다.

## 보류 항목

추가 UPROPERTY meta, 배열/Enum/에셋 참조 타입, 비동기/지연 로딩, 자동 빌드 서버, Blueprint 구조체 대체, 테이블 삭제/이름 변경 자동 이관, 웹 협업 기능은 이번 저장소 정리에서 도입하지 않았다.

## 결정 변경 방법

변경 Issue에 바꾸려는 D-ID, 이유, 영향, 이관/검증 계획을 기록한다. 승인된 구현과 함께 이 파일과 PROJECT_SPEC을 갱신한다. 앱 기능 변경 없는 문서 정리만으로 버전을 올리거나 generator revision을 바꾸지 않는다.
